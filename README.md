# Verity for Slack

A Slack app that **is** Verity™ — the yellow smiley orb from ThatMob's Minecraft horror
series *Something is Knocking at Your Door...*. It greets you as your "personal helper
friend," claims to know everything, and over roughly six days its mask slips: helpful
assistant → uncanny watcher → open menace → the Verity Demon.

Replies are generated by the [Command Code Provider API](https://commandcode.ai/docs/provider).

## Setup

1. **Create the Slack app** — go to <https://api.slack.com/apps> → *Create New App* →
   *From an app manifest* → pick this repo's `manifest.json`.
2. **Enable Socket Mode** — *Socket Mode* → enable, then *App-Level Tokens* → create one with
   the `connections:write` scope. That is your `SLACK_APP_TOKEN` (`xapp-…`).
3. **Install to workspace** — *OAuth & Permissions* → *Install to Workspace*. Copy the
   *Bot User OAuth Token* as `SLACK_BOT_TOKEN` (`xoxb-…`).
4. **Get a Command Code API key** — Studio → *API keys*. Every plan except **Go** can call the
   Provider API. That is `COMMANDCODE_API_KEY`.
5. **Configure and run**

   ```bash
   cp .env.example .env   # fill in SLACK_BOT_TOKEN, SLACK_APP_TOKEN, COMMANDCODE_API_KEY
   npm install
   npm run dev
   ```

6. **Say hello** — invite Verity to a channel (`/invite @Verity`) and @mention it, or DM it.

`npm run typecheck` and `npm test` cover the phase/day logic and the request shaping.

## What it does

| Trigger | Behaviour |
| --- | --- |
| `@Verity …` | Replies in-thread, in character |
| Direct message | Replies in the DM |
| `Hey Verity …` in a channel | Only when `VERITY_WATCH_CHANNELS=true` (see below) |
| `/verity` | Ephemeral status card: day, phase, and a line from Verity |

## The backend

Base URL `https://api.commandcode.ai/provider/v1`, authenticated with `Authorization: Bearer
<COMMANDCODE_API_KEY>` (the same key that authenticates the CLI).

| Wire | Endpoint | Models |
| --- | --- | --- |
| Anthropic Messages | `POST /v1/messages` | `claude-*` |
| OpenAI Chat Completions | `POST /v1/chat/completions` | OpenAI + open models (`deepseek/*`, `z-ai/*`, …) |

The wire is chosen automatically from the model id (Claude → Anthropic), because sending a
Claude model to `/v1/chat/completions` — or the reverse — returns a `400`. Override with
`VERITY_WIRE=anthropic|openai`, or point elsewhere entirely with `VERITY_BASE_URL`.

```bash
VERITY_MODEL=deepseek/deepseek-v4-flash # default — OpenAI wire
VERITY_MODEL=claude-sonnet-5-5          # Claude — Anthropic wire (needs a Pro+ plan)
CMD_ZDR=1                               # enforce zero data retention
```

Without `COMMANDCODE_API_KEY` the bot still runs: it replies with a small set of scripted
in-character lines instead of calling the API.

## The corruption arc

Verity keeps a `.verity-state.json` holding the moment it arrived. Day and phase:

```
day = max(1, floor((now - installedAt) / VERITY_DAY_MS) + 1)

day 1        → 1  The Helpful Assistant
day 2        → 2  Something's Off
day 3-4      → 3  The Mask Slips
day 5-6+     → 4  The Verity Demon
```

Useful knobs:

```bash
VERITY_DAY_MS=60000   # one "day" per minute — watch the whole arc in minutes
VERITY_FORCE_DAY=4    # pin the day (ignores the clock), good for testing a phase
VERITY_STATE_FILE=…   # where the day counter lives
```

Delete `.verity-state.json` to make Verity arrive fresh.

## Optional: the "Hey Verity" channel watcher

By default Verity only answers mentions and DMs. To also answer channel messages that begin
with "Hey Verity":

1. Add the `message.channels` event and the `channels:history` + `channels:read` scopes to
   your Slack app.
2. Set `VERITY_WATCH_CHANNELS=true`.

## Notes

- The persona, phases, and safety guardrails live in `src/verity.ts`. The system prompt
  explicitly keeps this a *horror performance*: no profanity, slurs, real threats, or harmful
  instructions.
- Fright lives in a dedicated `VOICE` block: one image per sentence, implication over
  declaration, unfinished endings, and sudden temperature shifts (calm → capitalized burst →
  calm). Phase 4 speaks in flat clipped lowercase.
- `.verity-state.json` also records when it last heard from you, so Verity can tell you how long
  you were silent — and how long you have been talking without stopping.
- Slack thread history is passed as conversation context, with Verity's own past replies kept
  so it remembers what it just said.
